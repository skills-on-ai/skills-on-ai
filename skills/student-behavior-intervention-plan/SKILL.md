# Student Behavior Intervention Plan

A behavior intervention plan (BIP) is a targeted, individualized plan
addressing one student's specific, recurring behavior pattern: what
triggers it, what function it serves for the student, and what
replacement behavior and response system will actually change it.
It's narrower than [[classroom-management]], which builds whole-group
systems rather than responding to one student's pattern, and narrower
than an [[individualized-education-program]], the broader legal
document a behavior plan may sit inside when the behavior is tied to a
documented disability.

## Key components

- **Functional behavior assessment** — a specific analysis of what
  reliably precedes the behavior (the antecedent) and what the student
  gets or avoids as a result (the function), since an intervention
  aimed at the wrong function won't change anything.
- **Operationally defined target behavior** — a precise, observable
  description of the behavior being addressed, specific enough that
  two different observers would agree on whether it occurred.
- **Replacement behavior** — a specific, teachable alternative that
  serves the same function for the student as the problem behavior
  did, so the underlying need doesn't go unmet.
- **Response plan** — what adults do, consistently, both when the
  replacement behavior appears (reinforce it) and when the target
  behavior still occurs (a planned, predictable response, not an
  improvised one).
- **Data collection method** — a simple, consistent way to track
  frequency, duration, or intensity of the behavior over time, so the
  plan's effect can actually be measured rather than assumed.
- **Review interval** — a set point at which the data gets reviewed
  and the plan adjusted if it isn't working.

## Targeting the function, not just the behavior

The single most common reason a behavior plan fails is that it
targets the visible behavior without ever identifying what function
that behavior serves for the student — a plan that punishes
disruption without addressing why the student disrupts (to escape a
hard task, to get peer attention, to avoid an anxiety-inducing
situation) tends to see the behavior resurface in a different form,
because the underlying need it was meeting hasn't gone anywhere. This
is why the functional behavior assessment isn't an optional first
step; it's what makes the rest of the plan aim at the right target.
Once the function is identified, the replacement behavior has to be
genuinely functional too — teaching a student to raise their hand
instead of calling out only works as a replacement if raising their
hand actually and reliably gets them the same thing (attention, help,
a break) that calling out used to.

## Common pitfalls

- **No functional assessment** — designing a response to the visible
  behavior without ever determining what function it serves produces
  a plan that treats the symptom and leaves the cause intact.
- **Replacement behavior that doesn't serve the same function** — a
  substitute behavior technically taught but that doesn't actually get
  the student what they were seeking rarely gets used when it counts.
- **Inconsistent adult response** — the plan's response only works if
  every adult who interacts with the student applies it the same way;
  inconsistency teaches the student the plan is negotiable.
- **No data, or data no one reviews** — collecting behavior data but
  never reviewing it against the plan's goal wastes the one signal
  that shows whether the intervention is actually working.
- **Treated as permanent** — leaving a plan unchanged long after the
  data shows it isn't working, rather than using the scheduled review
  to revise it.
