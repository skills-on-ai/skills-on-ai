# Locale: Marathi (India) (mr-IN)

Reference data for the **Marathi (India)** locale — endonym **मराठी (भारत)**, written in the Devanagari script, left-to-right (LTR).

## Identifiers

- **BCP 47 tag:** `mr-IN`
- **ISO 639-1:** `mr`
- **ISO 639-3:** `mar`
- **Script:** Deva (Devanagari)
- **Region:** IN (India)
- **Text direction:** ltr — left-to-right (LTR)

## Speakers (approximate)

- **L1 (native):** 83,000,000
- **L2 (additional):** 16,000,000
- **L1+L2 (total):** 99,000,000

This is a regional variant of [[locale-mr-001]] (Marathi), the base/macro locale for this language.

CLDR plural categories for this locale: **one**, **other** (2 forms).

- **one** — `n = 1` (e.g. 1)
- **other** — everything else (e.g. 0, 2~16, 100, 1000, …)
