# Locale: Tatar (Russia) (tt-RU)

Reference data for the **Tatar (Russia)** locale — endonym **Татар теле (Россия)**, written in the Cyrillic script, left-to-right (LTR).

## Identifiers

- **BCP 47 tag:** `tt-RU`
- **ISO 639-1:** `tt`
- **ISO 639-3:** `tat`
- **Script:** Cyrl (Cyrillic)
- **Region:** RU (Russia)
- **Text direction:** ltr — left-to-right (LTR)

## Speakers (approximate)

- **L1 (native):** 5,300,000
- **L2 (additional):** 1,200,000
- **L1+L2 (total):** 6,500,000

## Base locale

This is a regional variant of [[locale-tt-001]] (Tatar), the base/macro locale for this language.

## Pluralization

CLDR has no explicit plural rule defined for this language; it falls back to the root rule of a single **other** category (1 form) — every count uses the same word form, as in Japanese or Chinese.

See [[unicode-messageformat]] for writing plural messages using these categories.
