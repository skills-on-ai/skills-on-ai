# Daily Reset Block

A daily reset block is a short, protected slot, often fifteen to thirty
minutes as a starting default, in which the user clears the small mess
that has built up and starts again cleanly. It deals with the desk, the
inbox pile, loose tasks, and the state of mind.

It differs from [[home-reset-system]], which resets the house, and from
[[tomorrow-setup]], which prepares the next day. The reset block resets
today so the rest of it works.

## Input required

- **Work pattern**: office, home, shifts, caregiving.
- **Where the mess builds up**: desk, inbox, messages, notes, tabs, head.
- **Fixed points in the day** where a block could sit.
- **What interrupts** the user most.

## Questions to ask first

Ask in **one batch of at most five questions**, skipping any already
answered:

1. When in the day does it fall apart (late morning, after lunch, evening)?
2. Which piles grow most: desk, email, messages, loose tasks, or notes?
3. How long can you protect, on a bad day and on a good day?
4. What would make a reset feel finished?
5. Do others need to know you are unavailable during it?

## Method

1. **Choose the slot.** Put it after a natural break, at the point where
   the day usually slumps, or at the end of work. Name a fixed time and
   put it on the calendar as an appointment that others can see.
2. **Set a timer** and a shorter version for rushed days (for example,
   five minutes of the three most important steps).
3. **Run the same sequence each time.**
   - **Body:** stand, stretch, water, a short walk or breath.
   - **Surfaces:** clear the desk to one item or none; return mugs and
     papers.
   - **Piles:** sweep the inbox, notes, and message threads into one of
     four outcomes (do in two minutes, schedule, delegate, drop).
   - **Loose tasks:** write every open loop on one list, then choose
     the next three.
   - **Head:** write down worries or unfinished thoughts in a line or two
     each; decide what can wait.
4. **Restart deliberately.** Choose the single next action, set it where
   it will be seen, and begin it before closing the block.
5. **Close the loop.** Tick the block off, and note anything that did not
   fit for tomorrow's [[tomorrow-setup]].
6. **Protect it.** Decline meetings that collide, silence notifications,
   and tell colleagues or family the time.
7. **Run on bad days.** The rule is that the short version always counts.
8. **Review weekly:** Is the slot right? Which step is skipped? Cut steps
   rather than skipping the block.

## Output format

- **The slot:** time, length, short version.
- **The checklist** in order, one line per step.
- **Rules:** where captured items go, and what counts as done.
- **Protection plan:** calendar entry, notification setting, message to
  others.
- **Review question** for the weekly check.

## Ground rules

- **Keep it small.** If it becomes a second work session, it stops
  happening.
- **Reset, not catch up.** The block clears and restarts; it does not
  carry heavy new work.
- **One list.** All loose tasks go to one place, not five.
- **Privacy.** Do not ask the user to paste confidential work content;
  work from categories.
- **Persistent overwhelm** that a reset cannot touch may call for a talk
  with a manager, a colleague, or a health professional. Say so gently.

## Self-check before answering

- Does the block have a fixed time, a timer, and a short version?
- Is the sequence identical each day?
- Does it end with the next action chosen, not just a clean desk?
- Is it clearly different from the house reset and the evening setup?
- Is protection from interruptions in the plan?

## Common pitfalls

- **A block that expands** into a long email session.
- **Optional timing,** so it happens "when I have time" and never.
- **Tidying only the desk** and leaving the inbox and head untouched.
- **No restart step,** so the clean desk is wasted.
- **Perfectionism:** a reset is good enough, not zero inbox.
- **Skipping on the worst days,** which is when it matters most.

## Example prompt

> By three o'clock my desk, inbox, and head are a mess. Design a
> twenty-minute daily reset block with a checklist, a five-minute
> version, and a way to protect it from meetings.
