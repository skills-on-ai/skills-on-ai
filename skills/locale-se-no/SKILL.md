# Locale: Northern Sami (Norway) (se-NO)

Reference data for the **Northern Sami (Norway)** locale — endonym **Davvisámegiella (Norga)**, written in the Latin script, left-to-right (LTR).

## Identifiers

- **BCP 47 tag:** `se-NO`
- **ISO 639-1:** `se`
- **ISO 639-3:** `sme`
- **Script:** Latn (Latin)
- **Region:** NO (Norway)
- **Text direction:** ltr — left-to-right (LTR)

## Speakers (approximate)

- **L1 (native):** 15,000
- **L2 (additional):** 5,000
- **L1+L2 (total):** 20,000

## Pluralization

CLDR plural categories for this locale: **one**, **two**, **other** (3 forms).

- **one** — `n = 1` (e.g. 1)
- **two** — `n = 2` (e.g. 2)
- **other** — everything else (e.g. 0, 3~17, 100, 1000, …)

See [[unicode-messageformat]] for writing plural messages using these categories.

## Translating into this locale

Apply [[locale-se-fi]] to Northern Sámi in Norway, where the Sámi Language Act (Sameloven) gives Sámi equal status with Norwegian in the Sámi administrative area.

- **Context:** Sámi is used in Sápmi administration, education, and media (NRK Sápmi); the Sámi Parliament (Sámediggi) is in Karasjok.
- **Formats:** Norwegian krone (`kr`); decimal comma; dates with Sámi month names; quotation marks `«…»`; 24-hour clock.
- **Terminology:** use Sámi Parliament and Giellagáldu terms for official content.

## Common pitfalls

- Using Finnish or Swedish place names in Norwegian-side material.
- Translating official terms through Norwegian.
- The general pitfalls in [[locale-se-fi]] also apply.
