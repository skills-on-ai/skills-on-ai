# Locale: Sanskrit (India) (sa-IN)

Reference data for the **Sanskrit (India)** locale — endonym **संस्कृतम् (भारतम्)**, written in the Devanagari script, left-to-right (LTR).

## Identifiers

- **BCP 47 tag:** `sa-IN`
- **ISO 639-1:** `sa`
- **ISO 639-3:** `san`
- **Script:** Deva (Devanagari)
- **Region:** IN (India)
- **Text direction:** ltr — left-to-right (LTR)

## Speakers (approximate)

- **L1 (native):** 20,000
- **L2 (additional):** 5,000,000
- **L1+L2 (total):** 5,020,000

## Base locale

This is a regional variant of [[locale-sa-001]] (Sanskrit), the base/macro locale for this language.

## Pluralization

CLDR has no explicit plural rule defined for this language; it falls back to the root rule of a single **other** category (1 form) — every count uses the same word form, as in Japanese or Chinese.

See [[unicode-messageformat]] for writing plural messages using these categories.
