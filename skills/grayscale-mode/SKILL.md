# Grayscale Mode

Grayscale mode removes color from the screen. Apps and notification
badges lean on bright color to draw the eye, so a gray phone can feel
less inviting to pick up. It is a small, reversible experiment. This
skill helps a user set it up, make it easy to toggle, and judge honestly
whether it helps them.

## Input required

- **Device and OS version** (phone model, operating system, any custom
  manufacturer skin).
- **Why they want it**: less mindless checking, less evening scrolling,
  or curiosity.
- **When** they want it on: always, evenings, or work hours.
- **Color dependence**: whether they rely on color for work, safety, or
  daily tasks.

## Questions to ask first

Ask in **one batch of at most five questions**, skipping any already
answered:

1. What phone and operating system version do you have?
2. When do you most want to reduce the pull of the phone?
3. Do you use color for anything important, such as photo editing, maps,
   charts, status lights, or color-coded calendars?
4. Do you have color vision deficiency or other accessibility settings
   already in use?
5. Would you rather have it on all day or on a schedule?

## Method

1. **Check for a reason not to.** If the user depends on color for work
   or safety, or has a color vision difference, treat this as optional and
   offer a scheduled or toggled version, not a permanent one.
2. **Find the setting; do not assume it.** The location and name vary by
   device, manufacturer, and OS version. Typical places are under
   accessibility, display, or screen time, with names such as color
   filters, color correction, or grayscale. Tell the user to confirm in
   their own settings, or search the settings app for "grayscale" or
   "color filter". If you are unsure of the current path, say so and
   point to the manufacturer's support pages rather than guess.
3. **Turn it on and look.** Use it for a minute to confirm the effect and
   check that nothing important became unreadable.
4. **Create a quick toggle.** Most systems offer an accessibility
   shortcut, such as a button press sequence, a floating button, or a
   control center tile, that switches the filter on and off. Set it up so
   exceptions take seconds.
5. **Plan the exceptions.** Decide in advance when to switch it off:
   taking and editing photos, checking maps, reading color-coded charts,
   paying with a color-coded interface, or showing something to someone.
   Switch it back on afterward.
6. **Consider a schedule.** If the device supports it, tie grayscale to
   evening hours or a focus mode. Otherwise a daily reminder to toggle
   will do.
7. **Run a two-week trial and review.** Note pickups, screen time, or just
   how it feels. Keep it, schedule it, or drop it.

## Output format

- **Where the setting lives** for the user's device, marked "confirm in
  your settings" where unsure.
- **Toggle shortcut setup**, step by step.
- **Exceptions list**: when to turn it off.
- **Schedule** if any.
- **Review plan**: what to notice after two weeks and the decision rule.

## Ground rules

- **Be honest about the effect.** It helps some people reduce checking
  and does little for others. Do not promise results or cite figures.
- **Do not assume the menu path.** It differs by device and version;
  have the user verify.
- **Accessibility first.** If color carries information the user needs,
  keep grayscale optional or skip it. Never suggest it as a substitute
  for support if the phone use feels out of control; a clinician or
  counselor is the right route for that.
- **Keep it reversible.** State how to turn it off before turning it on.
- **Do not request account details or passwords.**

## Self-check before answering

- Did I confirm the device and OS before giving steps?
- Did I tell the user to verify the path in their own settings?
- Is there a fast toggle and a list of exceptions?
- Did I ask about color dependence and color vision differences?
- Did I avoid promising an outcome?

## Common pitfalls

- **Expecting it to be enough** — the apps are still there; pair it with
  notification and app changes, or a blocker.
- **No quick toggle** — the user wades through menus, then gives up.
- **Forgetting exceptions** — photos, maps, and charts become awkward.
- **Always on despite a real need for color** — a safety or work problem.
- **Reading the pull of the phone as only a color issue** — habits and
  content matter more.
- **Following an outdated menu path** — the setting has moved or been
  renamed.

## Example prompt

> I want to try grayscale mode on my phone to cut down evening scrolling.
> I use maps and take photos. Help me find the setting on my phone, set
> up a quick toggle, and decide when to switch it off.
