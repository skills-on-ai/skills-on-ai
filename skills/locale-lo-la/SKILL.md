# Locale: Lao (Laos) (lo-LA)

Reference data for the **Lao (Laos)** locale — endonym **ລາວ (ລາວ)**, written in the Lao script, left-to-right (LTR).

## Identifiers

- **BCP 47 tag:** `lo-LA`
- **ISO 639-1:** `lo`
- **ISO 639-3:** `lao`
- **Script:** Laoo (Lao)
- **Region:** LA (Laos)
- **Text direction:** ltr — left-to-right (LTR)

## Speakers (approximate)

- **L1 (native):** 3,400,000
- **L2 (additional):** 800,000
- **L1+L2 (total):** 4,200,000

## Base locale

This is a regional variant of [[locale-lo-001]] (Lao), the base/macro locale for this language.

## Pluralization

CLDR plural categories for this locale: **other** (1 form).

- **other** — everything else (e.g. 0~15, 100, 1000, 10000, …)

See [[unicode-messageformat]] for writing plural messages using these categories.

## Translating into this locale

Apply [[locale-lo-001]] with the conventions of Laos.

- **Context:** Lao is the official language, and the government publishes in Lao; minority languages are used locally.
- **Formats:** kip (₭) after the amount; day/month/year; Buddhist Era is used alongside the Gregorian year in some documents.
- **Tone:** polite and respectful; titles and kinship terms matter.

## Common pitfalls

- Using Thai-language conventions or script forms.
- Using Western date formats in official forms.
- The general pitfalls in [[locale-lo-001]] also apply.
