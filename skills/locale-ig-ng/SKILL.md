# Locale: Igbo (Nigeria) (ig-NG)

Reference data for the **Igbo (Nigeria)** locale — endonym **Igbo (Naịjịrịa)**, written in the Latin script, left-to-right (LTR).

## Identifiers

- **BCP 47 tag:** `ig-NG`
- **ISO 639-1:** `ig`
- **ISO 639-3:** `ibo`
- **Script:** Latn (Latin)
- **Region:** NG (Nigeria)
- **Text direction:** ltr — left-to-right (LTR)

## Speakers (approximate)

- **L1 (native):** 31,000,000
- **L2 (additional):** 6,000,000
- **L1+L2 (total):** 37,000,000

## Base locale

This is a regional variant of [[locale-ig-001]] (Igbo), the base/macro locale for this language.

## Pluralization

CLDR plural categories for this locale: **other** (1 form).

- **other** — everything else (e.g. 0~15, 100, 1000, 10000, …)

See [[unicode-messageformat]] for writing plural messages using these categories.

## Translating into this locale

Apply [[locale-ig-001]] with the conventions of Nigeria.

- **Context:** Igbo is one of the major languages of Nigeria; English is the official language. Use Standard Igbo (Igbo Izugbe) in written content.
- **Formats:** naira (`₦`); dates in English or Igbo form; 24-hour clock; decimal point.
- **Tone:** warm and respectful, with greetings and titles for elders.

## Common pitfalls

- Using unmarked dialect spelling.
- Omitting dotted letters.
- The general pitfalls in [[locale-ig-001]] also apply.
